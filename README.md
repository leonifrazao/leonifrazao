Featured Systems

<br>

### MoraNode — Multi-Tenant Real Estate Management
> Enterprise-grade property management with event-driven architecture.

| Aspect | Implementation |
|--------|---------------|
| **Architecture** | Hexagonal (Ports & Adapters) — strict domain isolation |
| **Core** | Spring Boot 3.4+ · Java 21 · PostgreSQL |
| **Events** | Apache Kafka for real-time property availability invalidation |
| **Frontend** | React 19 with synchronized TypeScript types via OpenAPI codegen |
| **Quality** | 45+ unit tests · Green CI/CD · Contract-first API design |

```
Contract Finalized ──▶ Kafka Event ──▶ Property Cache Invalidation ──▶ Availability Updated
```

### Argos — Visual Compliance & PPE Detection with Multi-Tenant RAG
> Privacy-first computer vision system with retrieval-augmented generation.

| Aspect | Implementation |
|--------|---------------|
| **AI Pipeline** | Python 3.12 · YOLOv8 · Gemini 1.5 Flash |
| **Vector Store** | ChromaDB with tenant-isolated namespaces |
| **Privacy** | `where={"company": "tenant_id"}` filtering prevents cross-tenant hallucinations |
| **Resilience** | Pydantic structured outputs · Exponential backoff via Tenacity |

```
Camera Feed ──▶ YOLOv8 Detection ──▶ PPE Compliance Check ──▶ RAG Context ──▶ Gemini Decision
```

### Parallax — Geopolitical OSINT Narrative Analysis
> Local-first intelligence pipeline for narrative drift detection.

| Aspect | Implementation |
|--------|---------------|
| **Services** | FastAPI microservices architecture |
| **LLM** | Ollama local deployment — zero cloud data egress |
| **Dedup** | RapidFuzz token set ratios for wire story deduplication |
| **Insight** | Maps narrative drift across media sources in real-time |

```
News Ingestion ──▶ Fuzzy Deduplication ──▶ Local LLM Analysis ──▶ Narrative Drift Map
```

## Engineering Principles

<p align="center">
  <table>
    <tr>
      <td align="center"><b>Hexagonal Architecture</b></td>
      <td align="center"><b>Clean Code</b></td>
      <td align="center"><b>Defensive Programming</b></td>
      <td align="center"><b>Event-Driven Design</b></td>
    </tr>
    <tr>
      <td align="center">Domain isolation through Ports & Adapters pattern. Infrastructure is replaceable.</td>
      <td align="center">Readable, maintainable, self-documenting code. No clever hacks.</td>
      <td align="center">Fail fast, validate at boundaries, never trust external input.</td>
      <td align="center">Async communication via message brokers for loose coupling.</td>
